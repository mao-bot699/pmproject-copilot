## Product Positioning

PMProject Copilot 是一款面向AI产品经理求职者的AI SaaS工具，帮助用户将模糊的产品想法快速转化为结构化的、可用于简历和面试的AI产品经理项目方案包。用户只需输入项目想法、目标角色和产品类型，即可获得包含产品定位、目标用户、PRD草案等模块的完整项目文档。

## Target Users

1. 正在求职AI产品经理岗位的候选人，需要快速生成可展示的项目方案。
2. 转行进入AI产品领域的产品经理，缺乏实际项目经验。
3. 需要为面试准备多个产品案例的产品经理。
4. 参加产品经理培训或课程的学生，需要完成项目作业。

## Pain Points

1. 求职者缺乏实际AI产品项目经验，难以在简历和面试中展示能力。
2. 从零构思一个完整的AI产品方案耗时耗力，且容易遗漏关键模块。
3. 现有AI工具（如ChatGPT）生成的内容结构松散，需要大量手动调整。
4. 缺少针对AI产品经理岗位的定制化项目模板和输出格式。

## PRD Draft

目标：帮助AI产品经理求职者快速生成结构化项目方案，提升简历和面试竞争力。
用户流程：1. 用户打开首页，输入项目想法、选择目标角色和产品类型。2. 点击生成按钮，系统调用DeepSeek API生成项目方案。3. 结果以卡片形式展示各模块内容（产品定位、目标用户、PRD草案等）。4. 用户可复制单个模块或导出Markdown格式完整文档。
关键模块：产品定位、目标用户、痛点分析、PRD草案、MVP功能、技术方案、成本估算、风险、7天计划、简历要点、面试故事、演示指南。
建议跟踪指标：生成次数、平均生成时间、复制次数、导出次数、用户停留时间。

## MVP Features

1. 结构化项目想法输入：用户输入项目想法（文本）、选择目标角色（下拉选项）和产品类型（下拉选项）。
2. AI生成项目方案：调用DeepSeek API，根据输入生成包含12个模块的结构化项目包。
3. 模块化结果卡片展示：每个模块独立卡片，清晰展示内容。
4. 单个模块复制：点击卡片上的复制按钮，复制该模块内容到剪贴板。
5. 导出Markdown：一键导出完整项目方案为Markdown文件。

## Tech Plan

前端：Next.js App Router + TypeScript + Tailwind CSS。
后端：Next.js API Route（/api/generate），调用DeepSeek API。
部署：Vercel。
环境变量：DEEPSEEK_API_KEY。
v1无数据库，无登录，仅支持复制和Markdown导出。

## Cost Estimate

成本主要由DeepSeek API调用产生，取决于输入长度、输出长度和调用次数。Vercel MVP阶段可使用免费额度。成本控制策略：限制输入长度（如项目想法不超过500字），控制输出长度（如每个模块不超过300字），避免高频重复生成。

## Risks

1. AI输出质量不稳定：DeepSeek API可能生成不准确或逻辑不一致的内容。
2. Prompt稳定性：不同输入下输出格式可能不一致，需要精心设计prompt。
3. 用户输入模糊：项目想法过于简单导致生成内容空洞。
4. API成本：频繁调用可能产生费用，需设置调用频率限制。
5. API延迟：生成多个模块时可能响应较慢。
6. 隐私期望：用户可能担心项目想法泄露，需声明数据仅用于生成且不保存。

## Demo Guide

1. 打开首页，页面左侧为输入区，右侧为结果展示区。
2. 在“项目想法”文本框中输入你的产品创意，例如“AI简历优化工具”。
3. 在“目标角色”下拉菜单中选择“AI产品经理”。
4. 在“产品类型”下拉菜单中选择“AI SaaS”。
5. 点击“Generate Project Plan”按钮，等待AI生成。
6. 生成完成后，右侧会显示多个结果卡片，每个卡片对应一个模块（如产品定位、PRD草案等）。
7. 点击任意卡片上的“Copy”按钮，复制该模块内容。
8. 点击页面顶部的“Export Markdown”按钮，下载完整项目方案的Markdown文件。
